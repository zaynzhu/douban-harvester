# README 重写设计

## 目标

重写 douban-harvester 的 README.md，平衡专业性与可读性，让开发者和普通豆瓣用户都能快速理解项目价值并上手使用。

## 目标读者

两者兼顾：技术用户（能跑代码导出数据）和非技术用户（想了解这个工具能做什么）。

## 风格方向

**平衡型**：专业但不冰冷，有温度但不煽情。参考 ripgrep/fd 的简洁风格，加上适度的 emoji 图标增加辨识度。

## 结构设计

### 1. 顶部

- 标题：`# 🌾 豆瓣收割机`
- Slogan（引用块）：`> 你的豆瓣评分和影评，一键导出。无需登录，安全第一。`
- Badge 行：Node ≥18 · TypeScript · MIT License

### 2. 核心亮点（4 条，emoji 图标列表）

- 🔒 无需登录 — 不碰账号，只读公开页面
- 🔄 三种模式 — 全量/增量/修补，自动判断
- 💾 断点续爬 — 中断后自动继续
- 🛡️ 防风控优先 — 随机延迟、有头浏览器、自动停止

### 3. 快速开始（三步走）

- 安装：`npm install` + `npx playwright install chromium`
- 配置：`.env` 中设置 `DOUBAN_USER_ID`，附提示说明 ID 在哪找
- 运行：三个命令（start/full/repair），说明首次用 start

### 4. 运行模式表格

五列模式对比表（交互式/全量/增量/修补/验证）。

### 5. 防风控

- 四条策略 + 引用块警告（不要减小延迟、不要 headless、不要移除反检测）

### 6. 数据文件表格

- 五个文件说明 + 底部一句"所有数据文件已在 .gitignore 中排除"

### 7. 项目结构

- 带一句话注释的文件树

### 8. 配置项表格

- config.ts 可调参数（5 项）
- 环境变量表合并到快速开始中，不重复

### 9. 技术栈

- 一行横排：TypeScript · Playwright · ExcelJS · tsx · dotenv

### 10. License

- MIT

## 与现有 README 的差异

1. 新增 emoji 标题 + slogan 引用块，第一眼就有印象
2. 新增「核心亮点」段，4 条价值主张一目了然
3. 防风控警告从普通文本改为引用块 callout，更醒目
4. 环境变量表从配置项段移到快速开始，减少来回跳转
5. 项目结构每行加一句话注释
6. 技术栈从列表改为一行横排，更紧凑
7. 整体信息量不变，但层次更清晰、阅读动线更顺

## 约束

- 不新增需要维护的内容（如截图、动画 GIF）
- 不引入外部依赖或 CI badge（项目没有 CI）
- 保持中文为主
